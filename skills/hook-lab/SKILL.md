# Hook lab

Every clip gets 3 hooks from 3 different styles (curiosity, stakes, question, reaction, number, tip, pov) and 3 matching covers (`cover_1..3.jpg`).
- Slot 1: the style with the best learned win rate (`learning-loop`).
- Slot 2: the style the signals suggest (chat spike -> reaction, most replayed -> curiosity).
- Slot 3: the least-tested style, so the loop keeps learning.

You may rewrite hooks to be sharper: under 8 words, a reason to keep watching, no clickbait lies, no spoilers. Keep the style label. Post hook 1 with cover 1 unless the user picks otherwise, and record which one went out.

Nothing is uploaded automatically. The user approves every post.
