# Cheat codes

List: `python "${CLAUDE_PLUGIN_ROOT}/moneyprinter.py" cheats`. Carousel: `python "${CLAUDE_PLUGIN_ROOT}/moneyprinter.py" cheats carousel --handle @yourpage` (4 PNG slides + caption.txt).

Answer only from `data/cheats.csv`. Every row has a `source` and `source_url` column and the status `reported`. Never add a code from memory or from a viral image. Nothing is uploaded automatically. The user approves every post.
